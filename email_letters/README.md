# Email-письма

HTML-шаблоны писем **Digital Memory**. Папка живёт в репе фронта только для
отслеживания изменений: она **не участвует в сборке** (`tsc` смотрит только в
`src`, `vite build` собирает от корневого `index.html` и `public/`), в `dist`
не попадает и кодом приложения не импортируется.

Для превью просто откройте нужный `.html` в браузере.

## Письма

| Файл | Письмо | Переменные |
| ---- | ------ | ---------- |
| `password-reset.html` | Восстановление пароля | `{{reset_link}}` |
| `password-changed.html` | Пароль изменён | — |
| `new-comment.html` | Комментарий администратора по материалу (модерация) | `{{comment_text}}` |

Переменные в формате `{{snake_case}}` подставляются на бэке при отправке.

## Общие правила вёрстки

- Табличная разметка (`role="presentation"`), инлайн-стили — email-safe подход.
- Хедер — одна картинка `https://digital-memory.ru/emailphoto_1.png` блоком на всю
  ширину письма (`display: block; width: 100%`), без абсолютного позиционирования,
  трансформаций и наложений — в письмах они не поддерживаются (Outlook, мобильные клиенты).
- Контентная колонка: 600px, паддинг 0 31px (ширина текста 538px).
- Кнопка (пока только в письме о восстановлении пароля): фон `#534035`, текст белый 18px bold, скругление 20px, высота 66px.
- Серая мелкая подпись внизу — `14px #666666`.
